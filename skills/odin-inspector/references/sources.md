## Coverage boundaries

Covers attributes, serialization decisions and API, AOT, editor windows and menu trees, drawers, resolvers, processors, validation and project setup. Not covered in depth: custom property resolvers, custom serialization formatters, UI Toolkit integration internals, Visual Designer file format and license management. Use the API documentation root for these. No Sirenix binaries, website snapshots or proprietary examples are bundled.
